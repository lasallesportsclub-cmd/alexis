# Événements LA SALLE : lancements Les Mills (chaque trimestre)

Chaque trimestre, LA SALLE lance les nouvelles chorégraphies Les Mills pendant un après-midi avec les profs, en général le samedi à partir de 16h.
Règle : le lancement suivant a lieu 3 mois après le précédent. Un mail de rappel part vers l'équipe 1 mois avant (J-30).
